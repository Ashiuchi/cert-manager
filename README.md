# 🚀 Cert-Manager: Roadmap para Analista Microsoft Pleno

O **Cert-Manager** é um ecossistema pessoal de gestão de carreira e finanças, projetado para monitorar a jornada de certificações Microsoft (Azure & Security). O objetivo central é gerenciar o progresso técnico da trilha **AZ-900 até o nível Expert**, integrando planejamento financeiro e inteligência de mercado.

---

## 🎯 Objetivo do Projeto
Transformar a jornada de estudos de um **Analista de Suporte Júnior** em uma trajetória estruturada para o nível **Pleno**, unindo a experiência em Sistemas Operacionais com a formação acadêmica em **Segurança da Informação**.

## 🛠️ Funcionalidades Principais
- [ ] **Roadmap Interativo:** Visualização do progresso nas trilhas Azure e SC (Security & Compliance).
- [ ] **Study-Wallet:** Monitoramento de metas financeiras para pagamento de vouchers (exames em USD/BRL).
- [ ] **Web Watcher:** Automação (Scraper) para buscar vouchers gratuitos em Virtual Training Days da Microsoft.
- [ ] **Library:** Repositório centralizado de materiais de estudo, links do MS Learn e simulados.

## 🛣️ A Trilha de Ascensão (Microsoft Cloud & Security)

| Status | Exame | Nível | Foco Principal |
| :--- | :--- | :--- | :--- |
| 🔄 | **AZ-900** | Fundamental | Azure Cloud Services & OS |
| ⏳ | **SC-900** | Fundamental | Security, Compliance & Identity |
| 📅 | **AZ-104** | Associate | Azure Administrator (O "Coração" do Pleno) |
| 📅 | **SC-300** | Associate | Identity & Access (Entra ID / Active Directory) |

---

## 🏗️ Stack Tecnológica (Previsão)
- **Frontend:** React.js / Next.js (Foco em Dashboard modular).
- **Backend:** Node.js (API para gestão de progresso).
- **Automação:** Puppeteer / Cheerio (Para o Web Scraper de descontos).
- **Banco de Dados:** PostgreSQL ou Firebase (Sincronização em tempo real).

---

## 📈 Integração Financeira
O app calcula automaticamente o valor necessário para a próxima prova baseado na cotação atual, ajudando a definir quanto deve ser poupado mensalmente na conta de estudos.
